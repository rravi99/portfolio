Useless Box

I created a box where every time a switch was flipped, the arm would rise, open a lid, and flick the switch back to the original position. Then, it would reverse direction (driven by a motor), and lower back into the box where its motion was halted by a limit switch. This was a lot of fun to build! I added an Arduino to programmatically the motor, and added code to give the box some personality—with the inclusion of some pauses and some pulse width modulation, my box ended up quite mischievous.
