Full System

I built a computer system on a Mango Pi board (Risc-V) in the class CS107e: Computer Systems from the Ground Up. We started by directly working in assembly, and then moved up to embedded systems programming with C. I fully implemented everything from printf to heap memory allocation (malloc), graphics, a PS/2 keyboard driver, a double-buffered graphics display, and the shell. At the end, with all the code imported to my Mango Pi, you could directly interact with a console, type in and run shell commands, and see output–all through code I wrote! This was such an incredibly rewarding end to months of work, and made me really understand the internals and function of my system. In this class, I got lots of embedded system and bare metal programming experience, including working with the Mango Pi board, and some simple circuits. I truly learned what goes on behind the scenes with C (shoutout compiler optimization magic) and how to debug gnarly bugs even without unit tests and printf…
