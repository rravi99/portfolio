Karaoke Machine

I created a karaoke machine with a partner, building with a Mango Pi board! The user can select a song from a menu to display lyrics synced with a backing track. For each song, the backing track audio plays through stereo speakers (I2S) and displays time-synced lyrics on a monitor. Users can switch between songs, and also customize the color scheme (to whatever most inspires their inner pop star…) While the demo includes five 10-second song clips, our program is able to load full-length songs. Song loading occurs during compilation, so user interaction with the interface is lag-free! I worked lots with memory, interrupts, and graphics! I also worked on integrating the speaker and audio processing. Of course, I also did lots of user testing (aka singing…very loudly). I learned a lot about integration, working with both hardware and software, modular design, and debugging.
